# Niyam

**When the law changes, the code changes with it.**

Niyam is an AI agent that reads new government orders and keeps welfare
eligibility rules, written as code, in sync with the law. Every rule links
to the clause it came from. Built during neatHack 2026.

Rulebook maintained by the agent: [usv240/niyam-rulebook](https://github.com/usv240/niyam-rulebook)

Full README, demo and evidence links are added as the build progresses. See `hackathon.md` for the live build log.
